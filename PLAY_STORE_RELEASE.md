### Boraine Tech (Pty) Ltd — Production Deployment SOP

## 1. Executive Summary

**Yes, SOLO is 100% ready to be Bubblewrapped for the Google Play Store.**

SOLO is built on Next.js 14 as a Progressive Web Application (PWA) with:
- Web App Manifests (`/manifest.json`, `/manifest-rider.json`, `/manifest-driver.json`)
- Offline fallback Service Worker (`@ducanh2912/next-pwa` + `worker/index.ts` with `public/~offline`)
- Full Web Push Protocol integration for dispatch alerts and arrival chimes
- Digital Asset Links configured at `/.well-known/assetlinks.json`
- Privacy Policy and POPIA statutory compliance at `/privacy`

By using **Bubblewrap** (Google's official CLI tool), the PWA is packaged into an **Android App Bundle (.aab)** using a **Trusted Web Activity (TWA)**. This delivers:
1. **Full Google Play Store listing** (discoverable, installable from Play Store)
2. **Zero URL bar** (runs full-screen standalone, identical to native Android apps)
3. **Hardware delegation** (GPS geolocation, Web Push, camera access for KYC)
4. **Instant web updates** (UI/server fixes deploy to your web server immediately without requiring Play Store review delays)

## 3. Step-by-Step Bubblewrap Build Instructions

### Prerequisites
1. **Node.js** (v18+)
2. **Java Development Kit (JDK 17 or JDK 21)**
3. **Android SDK Command-Line Tools** (Bubblewrap can install this automatically on first run)

### Step 1: Install Bubblewrap CLI
Open your terminal (PowerShell or Bash) and install the Google Bubblewrap CLI globally:
```bash
npm install -g @bubblewrap/cli
```

### Step 2: Build the Android App Bundle (.aab)

Navigate to the respective directory:

#### For Rider App:
```bash
cd twa/rider
bubblewrap build
```

#### For Driver App:
```bash
cd twa/driver
bubblewrap build
```

#### First-time prompt notes:
- Bubblewrap will prompt you to generate or locate your signing key (`android.keystore`).
- **CRITICAL:** Store the keystore password and alias safely in your password vault. If you lose this key, you cannot update your app on the Google Play Store without creating a new package!

The output file will be:
`app-release-bundle.aab` (Ready to upload to Google Play Console).

## 4. Digital Asset Links Verification (`assetlinks.json`)

To remove the browser address bar completely and enable Trusted Web Activity verification:

1. When you create your Google Play Developer Console app, go to:
   **Setup** &rarr; **App Integrity** &rarr; **App Signing**.
2. Copy the **SHA-256 certificate fingerprint** generated by Google Play App Signing.
3. Open `public/.well-known/assetlinks.json` in this repository and replace `REPLACE_WITH_PLAY_APP_SIGNING_SHA256` with your fingerprint.
4. Deploy the change to `https://soloride.co.za/.well-known/assetlinks.json`.
5. Verify via Google's Asset Link tester:
   ```
   https://digitalassetlinks.googleapis.com/v1/statements:list?source.web.site=https://soloride.co.za&relation=delegate_permission/common.handle_all_urls
   ```

## 6. Play Console Data Safety Answers

When completing the **Data Safety** questionnaire in Google Play Console:

1. **Location:**
   - *Approximate location & Precise location:* **Yes**
   - *Collected:* **Yes** | *Shared with third parties:* **No**
   - *Purpose:* App functionality (matching riders and drivers, fare estimation).
2. **Personal Info:**
   - *Name, Email, Phone Number:* **Yes** (For driver/rider accounts and trip receipts).
3. **Financial Info:**
   - *Payment Info:* **No** (Processed off-device by Paystack PCI-DSS gateway).
4. **Photos / Videos:**
   - *Driver KYC Documents:* **Yes** (Driver license, PrDP, selfie for safety compliance).
5. **Security Practices:**
   - *Data encrypted in transit:* **Yes** (TLS/HTTPS).
   - *Request data deletion:* **Yes** (Via `compliance@soloride.co.za` or in-app ticket).

## 7. Operational Guidelines for Allan Boraine (Boraine Tech)

1. **Keep Web Assets Live:** Because the TWA loads `https://soloride.co.za`, make sure your production domain has a valid SSL certificate (Let's Encrypt / Cloudflare / Vercel).
2. **Never commit keystore private keys** to public GitHub repositories. Keep `*.keystore` inside `.gitignore`.
3. **Testing:** You can test the built bundle on an Android device immediately using:
   ```bash
   bubblewrap install
   ```
   (Requires USB debugging enabled on your Android phone).
